Типы параметров для формы (kind): textbox, dropdown, radio

Типы параметров для фильтра (filter_kind): checkbox, range

Если параметр должен быть в фильтре: "search_form": "checkbox"

Если параметр в фильтре должен быть развернут: "filter_default_toggle": true,

Пример настроек валидации:
